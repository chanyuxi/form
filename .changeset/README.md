# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`.

We use changesets to describe changes that should be included in the next release. Add a changeset with `pnpm changeset`, review the generated Markdown file, and commit it with your code change.

Useful commands:

- `pnpm changeset` creates a changeset.
- `pnpm version` applies pending changesets and updates the lockfile.
- `pnpm release` builds the package and publishes it.
